伤害计算先后
物理通用
格挡→等级增减→效果[如力量]→类魔咒→盔甲→减伤类效果
魔法通用
格挡→等级增减→魔法强度→类魔咒[可能无]→盔甲→减伤类效果


盔甲值减伤机制
X＝护甲值
A＝经盔甲前置减伤后的伤害
E＝一次减伤[其数值最终会接近于结构强度与阈值1的乘积]
D＝结构强度[可通过护甲增减]
T=结构特化
R＝锐伤防护[加算]
Rx＝锐伤防护[乘算]
B＝钝伤防护[加算]
Bx＝钝伤防护[乘算]
r＝锐伤特化[加算]
rx＝锐伤特化[乘算]
d＝结构穿透[加算]
t＝结构穿透[乘算]
b＝钝伤特化[加算]
bx＝钝伤特化[乘算]
Fx＝二次减伤率[单位%]
F＝最终伤害
Ex＝一次减伤最大值
C＝阈值1＝20
J＝阈值2＝100[数值越高，高免伤收益区间越长]
S＝二次免伤率理论值＝90%
K＝温和基准线＝60[系数越大，d数值越小]
Q＝2.8 线性倍率
q＝2 压制倍率
Lx＝自身等级
Ly＝目标等级
h＝温和值
WL＝权
m＝最终增减伤比例
P＝压制系数
Y＝属性压制系数
damage＝计算格挡后的伤害
agi＝敏捷
ten＝韧性[0，1]
G＝当前格挡
Gmax=格挡上限
origin＝最初伤害
W＝弱点等级
Br＝弱点击破
Eg＝其他属性所增加的格挡
N＝格挡吸收效率
Tr=恢复周期[非小于0部分]
Rg=每恢复周期恢复量
Go＝超出上限的格挡量
To＝超出上限的格挡衰减所需时间
Trx＝恢复周期[小于0时]
O＝格挡效率


减伤1:
E＝减伤1
Ex＝减伤1最大值
D＝结构强度[经增减计算后的值]
d＝结构穿透[加算]
T＝结构特化
t＝结构穿透[乘算]
X＝盔甲值
R＝锐伤防护[加算]
Rx＝锐伤防护[乘算]
r＝锐伤特化[加算]
rx＝锐伤特化[乘算]
C＝20 阈值1
E＝{(D-d)(1+T-t)·[(X+R-r)(1+Rx-rx)]}/{1+([(X+R-r)(1+Rx-rx)]/C)}
Ex＝0.65A[一次减伤最多降低原数值65%的伤害]
//

修正E
E=min(E,Ex)
//

减伤2:
S＝0.9 减伤理论值
X＝盔甲值
B＝钝伤防护[加算]
Bx=钝伤防护[乘算]
b＝钝伤特化[加算]
bx＝钝伤特化[乘算]
J＝100 阈值2
Fx＝S·[(X+B-b)(1+Bx-bx)]/{[(X+B-b)(1+Bx-bx)]+J}

Fx＝max(min(Fx，0.9)，0)
//


最终伤害＝(A-E)·(1-Fx)


等级
指下方经验条，死亡后清空
常规上限100级，到达上线后将无法获取额外经验值，当等级提升时，可给予玩家以下数值[L为等级]
生命值提升 min(5   ，0.005L) (四舍五入至1)
等级差值伤害增减计算
在伤害计算时优先级最高，实体攻击其他实体成功时或受到有来源的伤害时触发计算
常数部分[推荐值]

h＝(Lx-Ly)/[((Lx+Ly)/2)+K]

权修正:
WL＝权
Lx＝自身等级
Ly＝目标等级

WL＝0.25+0.75(max(Lx，Ly)/100)²
//

压制系数修正:
P＝压制系数
Lx＝自身等级
Ly＝目标等级
P＝(max(Lx，Ly)/100)^(3/2)
//

最终增减比例:
N＝1 理论减伤倍率
S＝5理论增伤倍率
q＝2 压制倍率
Q＝2.8 线性倍率
h＝温和值
e＝自然常数e
WL＝权
m＝最终增减比例
m＝min(1+N，max(1-N，1+Qh(WL)+qh|h|P)) h＜0
 ＝1+Qh(WL)[1+S(1-e^-qhP)] h≥0
//


暂时无用
γ＝(m-1)/N

最终伤害计算

造成伤害＝damage×m

格挡
符号为G
初始值为0

以下为格挡相关计算变量
X＝盔甲值
R＝锐伤防护[加算]
Rx＝锐伤防护[乘算]
B＝钝伤防护[加算]
Bx＝钝伤防护[乘算]
Eg＝额外格挡
D＝结构强度
T＝结构特化
O＝格挡效率
N＝格挡吸收效率
F＝初始伤害
Agi＝敏捷
Ten＝韧性
Gmax=[0.5X+0.5R(1+Rx)+0.5B(1+Bx)+Eg]D(1+T)(1+O)
N＝G/Gmax (G≥0.5Gmax)
  =0.5+G/Gmax(G≤0.5Gmax)
  
敏捷修正[实时]
Agi＝玩家速度+额外
  
格挡承伤
ΔG＝[min(FN，G)]x[1-Ten]
ΔHP＝origin-ΔG

格挡恢复
Tr=max(1,4/(1+agi))
Rg=Gmax[0.1×(1+Ten)]
G=min(G+Rg,Gmax)

超额格挡
Go＝G-Gmax

To=4(1+0.5Agi)

每秒衰减量为
Go/To

负格挡恢复
Trx＝1/(1+0.5agi)
恢复量:
G=min(G+Gmax(0.1+0.2Ten),0)

弱点
每{30/(1+0.05Agi)(1+Ten)}减少一层。
拥有弱点时受到伤害
ΔG＝Gmax×0.05W

Br弱点击破
获得时将格挡值降低至[-10Gmax/(1+0.5Agi)(1+2Ten)]，且持续时间内无法恢复。

弱点击破[标签]
拥有该标签的实体攻击[或拥有该标签的攻击]时，无视格挡。

护盾效果更改
副手手持时增加0.1格挡效率，举盾时获得Gmax的格挡，若举盾期间[？若无法检测可以改为潜行]受到伤害，获得15秒弱点击破，若被破盾，获得15秒弱点击破。

拥有格挡值时，消耗格挡值格挡即将受到的有来源伤害[如实体攻击，弹射物伤害]
